# Built-in legend preset names

The preset names accepted by the `builtin` argument of
[`add_legend()`](https://r.geolibre.app/reference/add_legend.md).

## Usage

``` r
builtin_legend_names()
```

## Value

A character vector of preset names.

## Examples

``` r
builtin_legend_names()
#> [1] "esa_worldcover" "nlcd"          
```
